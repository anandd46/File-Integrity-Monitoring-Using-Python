Reports

Download scan results as CSV. Cells that start with =, +, - or @ are prefixed with an apostrophe so spreadsheets cannot run them as formulas. A copy of each report is also saved to the configured export folder.

Report columns

report_generated_at, scan_id, monitored_directory, relative_path, integrity_status, previous_hash, current_hash, file_size_bytes, inspection_error

Reports contain only data the monitor stored about registered directories: no secrets, environment variables or unrelated filesystem information.
