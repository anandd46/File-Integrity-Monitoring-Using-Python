Security limitations

  • The tool detects differences when a scan runs. It does not prevent changes or block attackers.
  • A hash difference is an indicator to investigate. It does not identify who changed a file or whether the change is malicious.
  • The baseline is only as trustworthy as where it is stored. An attacker who can change both the files and the SQLite database could hide changes.
  • Changes made and reverted between two scans are not seen.
  • Single local user, bound to localhost. Exposing it to other computers needs authentication, HTTPS and further hardening.
  • The in-process worker suits one local process only, not multi-worker production servers.
